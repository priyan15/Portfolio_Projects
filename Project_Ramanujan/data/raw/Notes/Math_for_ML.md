# Math for ML


## Introduction

**The Core of Machine Learning:**

At its heart, machine learning consists of three main components: data, models, and learning. 
<br>
* Data is generally represented in numerical format as vectors (arrays of numbers) and matrices (tables of numbers). 
* A model is a mathematical function or probability distribution that approximates the real-world process that generated the data. 
* Learning is the process of using optimization algorithms to automatically adjust the parameters of the model so that it fits the training data and generalizes well to unseen future data
